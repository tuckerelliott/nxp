# columns-banner

Custom **columns** block. Purpose: boxed promotional banner with a text column beside a photo.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row with two cells in visual order; text cell = heading, paragraph (inline links allowed), CTA link; image cell = a single picture. Put the image in the first cell for image-left banners.

A paragraph containing only a link becomes a pill CTA: orange `primary` in text-first banners, gradient-outlined `secondary` in image-first banners. Bold/italic link formatting (global button convention) overrides that default.
