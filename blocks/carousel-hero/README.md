# carousel-hero

Custom **carousel** block. Purpose: full-bleed rotating homepage hero with one photo, eyebrow, title, description and CTA per slide, plus labelled progress indicators.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cell 1 = background image; cell 2 = optional short indicator label paragraph, eyebrow paragraph, H1/H2 title, description paragraph, CTA link. With two paragraphs before the heading the first becomes the indicator label; otherwise the heading text is used.

## Supported variations

No variations.
