# cards-overlap

Custom **cards** block. Purpose: row of three corporate cards (image, heading, text, 1-2 CTAs) that overlap the end of a colored band above.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card; cell 1 = image; cell 2 = H3 title, paragraph, 1-2 CTA links.
