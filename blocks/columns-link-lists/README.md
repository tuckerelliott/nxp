# columns-link-lists

Custom **columns** block. Purpose: side-by-side groups of resource links, each topped by a CTA link and a titled heading.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row; each cell = CTA link paragraph, H3 heading, bulleted list of links. Lists with more than 6 links render in two columns; with two cells the layout is 1/3 + 2/3.

## Supported variations

No variations.
