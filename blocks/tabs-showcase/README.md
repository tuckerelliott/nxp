# tabs-showcase

Custom **tabs** block. Purpose: tabbed showcase of application areas, each panel pairing an application card with a featured product card.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab; cell 1 = tab label (may include an icon); cell 2 = H3 title link, list of links, Learn more link, image; then the product card starting at the product image/H4: H4 title, short status line, description, Learn more link.

## Supported variations

No variations.
