# cards-news

Custom **cards** block. Purpose: news and blog feed cards with image, optional type label, linked title, date and author.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per item; cell 1 = article image; cell 2 = optional eyebrow paragraph, H3 linked title, date paragraph, "By" author link paragraph.

No variations.
