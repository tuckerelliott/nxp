# cards-spotlight

Custom **cards** block. Purpose: topic spotlight with one featured card (image, two CTAs) and a stacked list of text-only article/video cards.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card; cell 1 = image (featured card only, leave empty for list cards); cell 2 = eyebrow paragraph (Featured/Video/Article), H3 title (linked on list cards), description or meta line, CTA links. A card with an image becomes the featured card.

## Supported variations

No variations.
